# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a high priority for the Namdapha Certificate Portal. If you discover a vulnerability, please disclose it responsibly:

1. **Do not create public GitHub issues** for security vulnerabilities.
2. Email the vulnerability details directly to the maintainers or report via GitHub Private Vulnerability Reporting.
3. Include the following details:
   - Type of vulnerability (e.g. RLS bypass, XSS, token leakage)
   - Step-by-step reproduction instructions
   - Potential impact
4. We will acknowledge receipt within 48 hours and work on a mitigation patch.
